# Task Tracker Export Tool

A simple Python script that simulates fetching task data from an API and exports it to CSV for reporting.

## Features
- Simulates API call to return task data
- Outputs a clean `.csv` with all tasks
- Demonstrates basic automation and data formatting

## Technologies
- Python 3
- `csv` module

## Usage

python task_export.py
